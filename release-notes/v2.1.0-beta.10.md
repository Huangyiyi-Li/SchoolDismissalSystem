# v2.1.0-beta.10 LED 字号配置与仓库存储优化版

本版本增加 LED 三类字号的独立控制，并清理重复构建产物与无用工程空壳。

## 主要更新

- LED 配置新增“左侧标题字号”“行列标题字号”“单元格内容字号”。
- 三项均支持“自动”或 1-64 像素；旧配置默认使用自动，显示效果保持不变。
- 固定字号在单元格空间不足时会自动缩小，避免文字压线或越界。
- 行列标题字号同时作用于行政班的年级/班级标题，以及社团班的社团名称/列标题；单元格字号用于状态文字。
- 本地预览、发送测试画面和正式刷卡画面统一使用当前字号配置。
- 标签发版不再把安装包同时保存在 Actions Artifact 和 Release；非标签临时构建产物保留期缩短为 3 天。
- 删除未包含任何应用模块、也不参与当前构建的旧 Android/Gradle 空壳文件。

## 测试建议

1. 保持三项字号为“自动”生成预览，确认升级前后的布局基本一致。
2. 分别调整三项字号并重新生成预览，确认每项只影响对应文字。
3. 使用较大字号和密集布局，确认文字会自动缩小且不与表格线重叠。
4. 发送测试画面到真实 LED 屏，确认预览与屏幕字号一致。
