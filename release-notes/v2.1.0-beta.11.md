# v2.1.0-beta.11 语音播报节奏配置版

本版本允许学校按照现场音箱和环境噪声调整放学语音的播放节奏。

## 主要更新

- 设置页新增“语音播报”区域。
- 播报语速支持 Windows 系统默认或 `80-300` 自定义数值，数值越大语速越快。
- 每条放学语音支持重复 `1-10` 遍，默认保持 `3` 遍。
- 每遍间隔支持 `0-10` 秒；选择“自然停顿”时保持原有系统语音停顿方式。
- 设置保存后从下一条语音开始生效，无需重启软件。
- 未配置过新参数的旧版本自动保持原有语速、三遍播报和自然停顿。

## 测试建议

1. 保持“系统默认、3 遍、自然停顿”，确认升级前后播报节奏基本一致。
2. 取消系统默认，分别尝试 `130`、`160` 和 `190`，确认数值越大语速越快。
3. 设置重复 2 遍、间隔 1.0 秒，模拟刷卡并确认只在两遍之间停顿一次。
4. 保存设置后不重启软件再次模拟刷卡，确认新参数立即生效。
