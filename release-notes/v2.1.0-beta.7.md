# v2.1.0-beta.7 社团紧凑布局与手动预览版

本版本针对社团数量较多以及低配置 Windows 主机修改参数时预览卡顿的问题进行优化。

## 主要更新

- 行政班与社团班使用独立布局参数：行政班配置横向分区和每区年级行数，社团班配置横向组数和每组社团行数，范围均为 `1–6`。
- 社团班改为多组紧凑表格，每组包含独立的“社团名/状态”列；状态列保证 `放学中/已放学` 单行显示，空白状态仍可快速识别。
- 社团名优先使用较大字号单行显示，空间不足时自动缩小并最多分为两行；仍无法容纳时安全截断，避免越过表格边界。
- 默认社团布局为 `5组 × 4行`，每页最多20个社团；50个社团生成3页，布局参数可由学校自行修改。
- LED 预览改为手动触发，不再因为输入框每次变化自动重绘。
- “生成预览/重新生成预览”在后台线程执行；参数变化时保留上一次画面并提示重新生成，减少低配置电脑界面卡顿。
- Windows Release 构建新增完整 Python 测试步骤，测试失败时不再继续发布。

## 现场验证建议

1. 在 LED 设置页分别修改行政班和社团班布局，确认两类参数互不影响并可保存。
2. 同步30–50个社团，设置社团班为 `5组 × 4行`，点击“生成预览”，确认页面数量和翻页顺序。
3. 检查空白、`放学中`、`已放学`三种状态，确认状态文字始终保持单行且不接触竖线。
4. 检查较长社团名称，确认字体缩小或分为两行后仍不越界。
5. 连续修改像素、行数、组数和标题，确认不会自动生成；点击“生成预览”后窗口不会卡死。
6. 使用真实控制卡发送测试画面，确认社团页面、行政班页面和翻页间隔符合预览。
