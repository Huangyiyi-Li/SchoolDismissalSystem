# v2.1.0-beta.9 单双色 LED 状态显示版

本版本为 BX-6E1XP 增加单色/双色屏选择，并在双色屏上用三种颜色直接区分班级状态。

## 主要更新

- LED 配置新增“屏幕颜色”：单色、双色；旧配置默认保持单色，不改变现场原有显示。
- 单色模式继续使用“未放学为空、放学中/已放学显示文字”的规则。
- 双色模式固定使用：未放学黄色、放学中红色、已放学绿色；标题、表格线、年级和班级名称保持红色。
- 行政班与社团班、测试画面及本地预览统一使用同一套颜色规则。
- 示例状态预览覆盖未放学、放学中、已放学三种状态。
- 发送前读取控制卡屏幕颜色类型；软件选择与控制卡屏参不一致时停止发送并显示明确提示。
- 像素上限按仰邦 BX-6E1XP 规格区分：单色 512K、双色 256K，宽度均不超过 2048。

## 测试建议

1. 先由施工方在控制卡屏参中确认实际屏幕为单色或双色，再在软件中选择相同类型。
2. 选择双色并点击“生成预览”，确认可见黄色“未放学”、红色“放学中”和绿色“已放学”。
3. 点击“发送测试画面”，确认真实屏幕颜色与预览一致。
4. 分别模拟刷卡并等待已放学延迟，确认状态由黄色变红色，再变绿色。
5. 临时将软件颜色选成与控制卡不一致的类型，确认发送失败提示明确，随后改回正确类型。
6. 升级旧学校配置后保持默认单色，确认未放学仍为空且原有显示不变。
