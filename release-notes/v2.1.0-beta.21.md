# v2.1.0-beta.21 Windows 语音重复播报修复版

## 修复内容

- 修复 Windows 客户端“重复次数”设置为 2 次及以上、且“每遍间隔时间”为 0 秒（自然停顿）时，实际可能只播报 1 遍的问题。
- 自然停顿模式改为将全部重复内容一次性提交给 Windows SAPI/pyttsx3 播放，避免在同一个语音引擎上连续调用 `runAndWait()` 导致后续重复未实际出声。
- 保留非 0 秒间隔的逐遍播放逻辑，例如设置 1 秒间隔时仍按“播报 → 等待 1 秒 → 播报”的方式执行。
- 补充回归测试，验证 repeat count=3 时只启动一次播放循环，但提交内容完整包含 3 遍。

## 现场验证建议

1. 重复次数设置为 3 遍。
2. 每遍间隔时间设置为“自然停顿”。
3. 使用测试模式模拟任意班级刷卡。
4. 确认同一句“XX班正在放学”连续听到 3 遍。
5. 再将间隔设置为 0.5 秒或 1 秒，确认仍能按设置间隔播报 3 遍。
