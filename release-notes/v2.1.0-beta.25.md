# v2.1.0-beta.25 窄屏多班级展示

版本类型：Windows x64 预发布版本。

构建提交：`{{COMMIT_SHA}}`

## 主要变更

- 新增 A「按班号上下分区」：例如上区显示 1～7 班，下区显示 8～14 班，各区重复年级与班号表头。
- 新增 C「按班号分段轮播」：按班级列切页，页脚显示页码和本页班号范围，沿用翻页间隔。
- 每块屏幕可独立选择布局和每段班级列数。支持班号不连续、不同年级班数不同、名称班和自定义年级分页，缺班位置留空。
- 设置预览、LED 实际输出、测试节目、电脑展示使用相同规则。旧配置默认保持常规布局，社团班布局保持原规则。
- 基于 master `f2e5ffe`，补入 beta.24 `3ef5857` 的字号优化后开发。未引入 beta.23 离线语音方案，保留 master 仓库清理。

## 安装与使用

退出旧版并备份配置、数据后，运行 Setup 安装包，或将 ZIP 解压到独立目录使用。安装后确认主界面显示 beta.25。

设置 → 屏幕展示 → 选中屏幕 → 行政班布局选择 A/C → 设置每段班级列数 → 生成预览 → 保存。

例如六年级各 14 班：每段列数设为 7、每组年级数设为 6。A 的屏幕高度不足、字太小时选择 C。设置了“轮播每页年级”时，会优先按年级组合分组，再在每组内分段。

详细规则和现场验收见 [窄屏多班级展示](https://github.com/Huangyiyi-Li/SchoolDismissalSystem/blob/v2.1.0-beta.25/docs/led-class-segments.md)。

## 验证与限制

自动回归检查分段后的班级覆盖、状态对应、图片输出、旧配置迁移及各屏保存。发布流水线运行 Windows 测试、SAPI 合成检查，构建 Java Bridge、EXE、ZIP、Setup 和 SHA256 文件。

A 会占用更多高度；C 需要等待轮播。实际字号取决于学校数据、屏幕像素和文案。发布流水线通过不代表现场 Windows 安装启动、实际扬声器、控制卡显示或家长站位可读性已验收。
