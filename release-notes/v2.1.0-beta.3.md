# v2.1.0-beta.3 LED 状态持久化与版式配置版

本版本针对现场测试反馈补充以下能力：

- 开启测试模式后，立即切换 LED 屏为放学信息；关闭测试模式且不在放学时段时，恢复控制卡原节目。
- 同一天内持久保存“放学中”和“已放学”状态。放学期间退出并重新打开软件，班级状态会自动恢复。
- “放学中”倒计时也会持久保存；软件重启后继续剩余倒计时，到期自动转为“已放学”。
- 设置页新增“每屏年级数”，可配置 1–6 个年级。设置为 6 时，一至六年级显示在同一屏；超出设置数量时继续按翻页间隔轮播。

## 现场验证建议

1. 在非放学时段开启测试模式，确认 LED 立即出现放学班级表格。
2. 刷卡后等待班级从“放学中”变为“已放学”，关闭并重新打开软件，确认状态仍在。
3. 在设置中把“每屏年级数”改为 `6` 并保存，确认六个年级只生成一页；改为 `2`，确认重新按两年级一页轮播。
4. 关闭测试模式，确认非放学时段恢复 Ledshow 中原有节目。
