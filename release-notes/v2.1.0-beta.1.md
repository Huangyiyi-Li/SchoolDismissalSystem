# v2.1.0-beta.1 仰邦 LED 联调测试版

## 版本类型

预发布测试版，用于 BX-6E1XP 控制卡和 1024×96 单基色 LED 屏现场联调。

对应 Commit：`{{COMMIT_SHA}}`

## 主要变更

- 新增仰邦 BX-6E1XP Java SDK Bridge，支持通过网线向控制卡动态区发送画面。
- 新增 1024×96 单色班级状态表格，根据服务端实际下发的行政班按年级分页。
- 同一班级多个卡号按 `classId` 去重，不生成服务端未返回的班级。
- 每页显示两个年级，班级列数取所有年级实际班级数的最大值，多页由控制卡循环显示。
- 刷卡和服务端手动放学后，对应行政班状态显示为“放学中”。
- 设置页新增 LED 启用开关、控制卡 IP/端口、学校标题、翻页间隔、连接测试和测试画面。
- LED 连接或发送失败不会阻断原有语音播报和服务端放学通知。
- Windows Release ZIP 内附 Java Bridge、仰邦六代 SDK 依赖和 Java 8 运行时。

## 安装和测试方式

1. 下载 Windows x64 ZIP，不要只下载或单独复制 EXE。
2. 将 ZIP 完整解压到可写目录，并保留 EXE 同级的 `led-bridge` 目录。
3. 关闭 Ledshow，确保电脑能够 `ping 192.168.100.1`。
4. 打开“绑定学校”，完成学校数据同步。
5. 在 LED 设置中先执行“测试连接”，再执行“发送测试画面”。
6. 测试正常后勾选“启用 LED 状态屏”并保存。
7. 可开启客户端测试模式后刷卡，验证语音和 LED“放学中”状态。

## 已知风险和回退说明

- 本版本尚未在真实 BX-6E1XP 控制卡上完成验收，属于现场联调版本。
- 单基色屏只能通过文字区分状态，不支持同时显示红、黄、绿等多种颜色。
- 当前业务事件只明确提供“开始放学”，因此自动状态为“放学中”；“已放学”需等待服务端完成事件后接入。
- 测试时应退出 Ledshow，避免两个软件同时操作同一控制卡。
- 如需回退，请退出本版本并重新运行独立目录中的 `v2.0.3`，不要覆盖原目录。
