# v2.1.0-beta.23 Windows 离线中文语音

测试版。Windows 班级放学播报改用随安装包提供的离线中文语音模型，合成 WAV 后经普通音频设备播放，不再调用 SAPI/OneCore 语音引擎。适用于系统语音引擎缺失、但普通音频正常的电脑。保留播报遍数、间隔和语速设置。

安装：退出旧版后运行本版 setup 安装程序；安装完成后确认主界面显示 beta.23，再用班级放学通知检查扬声器实际出声。也可完整解压 ZIP 后运行客户端；不要只复制单个 EXE，语音模型目录必须与 EXE 同级。

风险：离线模型使安装包明显变大，旧电脑首次加载语音可能较慢。Windows CI 验证了真实中文 WAV 合成与打包文件；现场扬声器及学校网络通知仍需在目标电脑验收。若出现异常，可卸载本版并从 beta.22 Release 安装旧版，但旧版仍依赖该电脑缺失的系统语音引擎。
