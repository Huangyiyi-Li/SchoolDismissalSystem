# v2.1.0-beta.8 Windows 安装与开机自启优化版

本版本解决 ZIP 便携版移动目录后，旧 VBS 开机启动脚本报“系统找不到指定的文件（80070002）”的问题。

## 主要更新

- 新增 Windows Setup 安装包，默认安装到当前用户固定目录 `%LocalAppData%\Programs\数智家校放学系统`，无需管理员权限。
- 开机自启改为当前用户注册表启动项，不再创建 VBS，也不再依赖任务计划权限。
- 工具栏根据实际状态显示“启用开机自启 / 关闭开机自启 / 修复开机自启”。
- 启用、修复或关闭时自动清理旧 VBS 和旧任务计划，避免重复启动或旧路径报错。
- 注册表写入、旧入口清理失败时显示具体错误，并记录到本地操作日志。
- 卸载安装版时同步删除注册表启动项、旧 VBS 和旧任务计划。
- 保留 ZIP 便携包供临时测试，但移动便携版目录后需要重新启用或修复开机自启。

## 测试建议

1. 使用 Setup 安装包完成安装，确认程序位于当前用户固定目录并可正常连接 LED 控制卡。
2. 点击“启用开机自启”，重新打开软件后确认按钮显示“关闭开机自启”。
3. 重启或注销 Windows，确认程序能够自动启动，且不再执行 VBS。
4. 将旧版 VBS 放入 Startup 目录后点击“修复开机自启”，确认旧 VBS 被删除。
5. 点击“关闭开机自启”，确认再次登录时软件不会自动启动。
6. 在“本地日志”中确认启用、修复、关闭和失败原因均有记录。
