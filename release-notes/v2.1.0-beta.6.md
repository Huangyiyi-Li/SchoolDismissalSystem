# v2.1.0-beta.6 LED 预览与尺寸说明优化版

本版本针对 LED 设置页现场使用反馈优化预览和像素尺寸输入。

## 本次更新

- 本地预览由原始黑白 BMP 改为黑底红字，更接近单色红色 LED 屏的实际观感。
- 预览默认按 100% 像素显示，支持 25%–400% 放大缩小、恢复 100%、适应窗口和滚动查看。
- 像素尺寸规则在设置页直接说明：只填写正整数，宽度不超过 2048、高度不超过 1024、单色总像素不超过 524288（512K）。
- 不强制要求宽高为 8/16/32 的倍数；最终尺寸必须与施工方和控制卡屏参完全一致。
- 预览配置错误时显示具体原因，不再统一提示为“格式不正确”。
- Python 客户端和 Java Bridge 使用一致的尺寸边界校验。

## 现场验证建议

1. 打开 LED 设置页，确认预览为黑底红字。
2. 点击 `＋`、`－`、`100%` 和“适应窗口”，确认可缩放并通过滚动条查看完整画面。
3. 输入非倍数尺寸（例如 `1001×97`），确认在总像素范围内可以预览和保存。
4. 分别输入超宽、超高或总像素超限的尺寸，确认页面显示对应的具体错误。
5. 使用施工方确认的真实尺寸发送测试画面，确认预览布局与现场 LED 一致。
