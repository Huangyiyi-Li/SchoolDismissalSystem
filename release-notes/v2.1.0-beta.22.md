# v2.1.0-beta.22 Windows 重复播报修复

- Windows 播报改为直接调用系统 SAPI，并等待系统确认播放完成，避免 pyttsx3 播放循环提前结束或后续遍数不出声。
- 保留 1–10 遍、自定义语速、自然停顿和每遍间隔设置；退出软件时可以取消正在播放的语音。
- 操作日志增加语音开始、实际读取的遍数和间隔、播放完成、取消及错误信息，方便现场排查。
- 构建前增加真实 Windows SAPI 合成验证，对比一遍、自然停顿三遍、1 秒间隔三遍的 WAV 长度。

安装前请退出正在运行的旧版，安装后确认主界面显示 beta.22。保存 3 遍设置后，分别用自然停顿和 1 秒间隔验证实际扬声器播报。

Windows 合成和安装包检查不能代替现场扬声器验收。
