# v2.1.0-beta.2 仰邦 LED 现场联调修复版

## 版本定位

根据 BX-6E1XP、1024×96 单基色屏首次现场测试结果修复交互和播放问题。

## 本次修复

- 多年级翻页改为电脑按设置间隔逐张发送动态区图片，不再依赖控制卡固件对多页动态区的播放兼容性。
- 新增“已放学延迟(秒)”设置；班级刷卡后先显示“放学中”，到达间隔后自动显示“已放学”，重复刷卡会重新计时。
- 新增“清空状态/恢复原节目”，删除本客户端写入的动态区并恢复 Ledshow 普通节目。
- 行政班放学时段结束后自动清空全部班级状态、停止翻页并恢复原节目。
- 非行政班放学时段内不再因测试模式或数据同步写入 LED 屏。
- Windows 启动 Java LED Bridge 时使用无控制台窗口模式，避免刷卡时黑色终端窗口闪现。

## 现场复测建议

1. 在 Ledshow 中预先发送一个普通节目，随后退出 Ledshow。
2. 设置翻页间隔和已放学延迟，例如均设为 3 秒。
3. 点击“发送测试画面”，确认不同年级页面能够循环切换。
4. 点击“清空状态/恢复原节目”，确认 Ledshow 普通节目重新显示。
5. 在行政班放学时段内刷卡，确认“放学中”在设置间隔后变为“已放学”。
6. 等待行政班放学时段结束，确认状态清空、动态区停止且原节目恢复。
7. 重复刷卡，确认 Windows 不再闪现终端窗口。

## 说明

- 本版本仍为现场联调预发布版。
- 逐页发送使用控制卡 RAM 动态区，不写入普通节目 Flash。
- 软件只删除 ID 为 0 的本客户端动态区，不删除 Ledshow 已发送的普通节目。
