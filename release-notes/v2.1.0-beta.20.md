# v2.1.0-beta.20 小尺寸 LED 预览可读性提示

测试版，构建提交：`{{COMMIT_SHA}}`

## 修复与优化

- 192×96 等窄屏的左侧标题在横排文字过小时自动改为竖排，让标题利用屏幕高度；标题字号读数反映实际绘制大小。
- 预览某页实际字号小于 8 px 时，明确提示原生像素下可能难以辨认，并根据年级行数、班级列数和状态文字长度给出调整建议。放大预览只放大像素，不会被误认为提升实体屏清晰度。
- 保持自定义状态文案原样输出。小屏可手动将“放学中”“已放学”改成单字或空心/实心圆，并把年级分配到更多轮播页。

## 安装与验证

下载 Windows 安装程序或便携 ZIP。升级前退出旧客户端并备份 `data` 目录。安装后在“系统设置 → 屏幕展示”重新生成预览，逐页查看“本页实际字号”和可读性提示。

已在 macOS offscreen 环境运行完整 pytest 套件，并由 Windows GitHub Actions 构建安装包、便携 ZIP 和校验文件。现场 LED 屏、控制卡和读卡器效果仍需实测。
