# v2.1.0-beta.16 超高频十进制卡号识别修复

- 修复超高频四字节标签无法直接匹配后台十进制卡号的问题。例如有效数据 AE1DAF0B 转为 2921180939，自动查找当前学校对应班级，无需重复手工绑定。
- 保留手工标签绑定优先规则，失效绑定不会自动匹配其他班级。
- 主界面日志显示识别后的卡号，方便现场核对。
- 保留原近距离刷卡器、放学时段、语音去重、API 冷却和 LED 处理流程。

## 更新后测试

安装新版，确认已同步当前学校班级卡号，启用 TCP 7000，并退出标签采集状态后刷卡。示例报文应识别卡号 2921180939 及后台关联班级。

## 验证
