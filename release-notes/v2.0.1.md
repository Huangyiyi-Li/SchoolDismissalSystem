# v2.0.1 正式版

## 版本类型

正式版修复版本。

## 主要变更

- 测试模式启动时自动恢复为关闭，避免上次调试状态残留导致刷卡只本地播报、不推送服务端。
- 开启测试模式时增加二次确认，明确提示开启后不会推送服务端后台。
- 测试模式开启、关闭和启动自动关闭都会写入实时日志，便于现场追溯配置变更。
- 接口日志窗口增加协议、方向、结果和关键词筛选，并显示当前展示条数与最近加载条数。

## 安装或升级方式

- 使用 GitHub Actions 基于 `v2.0.1` Tag 构建的 Windows x64 Release 包升级。
- 升级前请退出旧版本客户端，再解压并运行新版 `数智家校放学系统.exe`。

## 已知风险和回退说明

- 接口日志仍按本地 JSONL 文件保留，界面默认加载最近 500 条；更多历史日志可通过“打开日志目录”查看。
- 如需回退，请退出本版本并重新运行独立目录中的 `v2.0.0`，不要覆盖原目录。
