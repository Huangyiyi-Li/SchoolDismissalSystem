# v2.1.0-beta.26 设置页重设计与精确班级筛选

版本类型：Windows x64 预发布版本；不替换稳定版 Latest。

构建提交：`{{COMMIT_SHA}}`

## 主要变更

- 设置页合并为“基础设置、读卡设备、屏幕展示”三个入口。学校绑定与语音播报放在基础设置，接口地址、设备编号和 MQTT 等低频选项可展开查看。
- 屏幕展示改为顶部切换屏幕，按“显示范围、布局、样式、设备”切换参数，预览和保存操作固定显示。保留共享方案、设备测试、恢复节目、全校状态重置和电脑展示。
- 显示范围支持精确到各年级的各班级，每块屏幕独立保存；支持班级搜索、搜索结果批量选择及失效班级提示。预览、测试屏、LED 实时输出和电脑展示使用同一筛选规则。
- 修复 C“按班号分段轮播”底部无法移除的页码／班号范围文字，表格使用完整可用高度。页码仍可在预览控件中查看。
- 保留旧配置兼容，未设置班级筛选的年级默认显示全部班级。显示范围只影响行政班展示，语音播报、日志、服务端通知和社团展示沿用原规则。

## 安装与使用

退出旧版，备份当前配置和数据，再运行 Setup 安装包；也可将 ZIP 解压到独立目录使用。启动后确认主界面版本为 v2.1.0-beta.26。

设置 → 屏幕展示 → 选择屏幕 → 显示范围 → 选择年级和班级 → 生成预览 → 保存并应用。

默认包含全部班级（含以后同步新增）。直接取消某个班级会切换为指定班级模式；重新勾选“包含全部班级”可恢复。整个年级都不展示时取消左侧年级勾选。搜索后的批量操作只影响当前年级的匹配结果。

功能位置见[设置页说明](https://github.com/Huangyiyi-Li/SchoolDismissalSystem/blob/v2.1.0-beta.26/docs/settings-workspace.md)，布局规则见[班级展示说明](https://github.com/Huangyiyi-Li/SchoolDismissalSystem/blob/v2.1.0-beta.26/docs/led-class-segments.md)。
