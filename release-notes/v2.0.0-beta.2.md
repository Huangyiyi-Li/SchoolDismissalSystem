## 版本类型

2.0 测试版（Pre-release）。

## 对应 Commit

`{{COMMIT_SHA}}`

## 主要变更

- 每个行政班、社团班放学时段开始前 2 分钟，精确触发一次最新数据同步。
- 保留客户端启动同步、手动“立即同步数据”和每 30 分钟定时同步。
- 产品名称、窗口标题、开机启动任务和 EXE 名称统一为“数智家校放学系统”。
- 主界面固定显示完整版本号。
- Windows EXE 使用指定品牌 Logo，并提供版本化 ZIP 和 SHA256 校验文件。

## 安装或升级

1. 退出旧版客户端。
2. 下载带“数智家校放学系统”中文标签的 Windows x64 ZIP 并解压。
3. 运行 `数智家校放学系统.exe`。
4. 首次启动后确认学校绑定、接口连接和放学时段数据正常。

## 已知风险和回退

- 本版本为测试版，建议先在联调电脑验证服务端数据同步、MQTT 指令和语音播报。
- 如需回退，请退出本版本并重新运行独立目录中的 `v1.0.0` 或 `v2.0.0-beta.1`，不要覆盖原目录。
