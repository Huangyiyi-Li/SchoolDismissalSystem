# v2.1.0-beta.18 电脑展示与多屏标题布局

测试版，构建提交：`{{COMMIT_SHA}}`

## 新增与修复

- 支持在同一台 Windows 电脑上选择显示器作为放学展示端，按显示器原生像素和 DPI 自适应布局，电脑输出默认双色模式。
- LED 屏和电脑展示均支持标题放在左侧或顶部；多块屏可复用显示方案。
- 顶部列标题按班号显示为“1班、2班、3班”，不再重复拼接年级；年级列、班级列和状态文字使用同一套自动排版计算。
- 电脑展示默认忽略历史 LED 手动字号，按实际窗口自动计算，避免旧配置导致 1080p 画面出现过小文字。
- 服务端 MQTT 指令兼容常见大小写和分隔符写法；全屏电脑展示提供鼠标“关闭展示”按钮，也支持 Esc 返回。

## 安装与升级

下载 Windows 安装程序或便携 ZIP。升级前退出旧客户端并备份 `data` 目录；首次启动后在“系统设置 → 屏幕展示”确认 MQTT、显示器、启用状态和标题位置，再使用“全屏测试展示”检查画面。

如需回退，退出客户端后安装 beta.17 并恢复升级前备份。服务端指令接收仍依赖 MQTT 已启用、设备编号正确以及网络可达；Windows CI 和本地自动化不能替代现场网络、DPI、双显示器及真实 LED 控制卡验收。
