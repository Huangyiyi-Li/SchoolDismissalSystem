## 主要变更

- 接入 2.0 数据接口，支持行政班、社团班放学通知推送与本地播报。
- 支持 MQTT 客户端在线心跳、服务端放学指令下发和处理回执。
- 新增 MQTT 连接失败重试机制；启动连接失败后默认每 60 秒重试，服务端中断重启后客户端可自动重连并重新订阅指令 topic。
- 支持接口网络日志查看，便于现场排查 HTTP 与 MQTT 联调问题。
- 支持放学时段开始前 2 分钟精确同步最新班级、卡号映射和放学时间表。
- 产品名称、窗口标题、开机启动任务、EXE 名称、版本号展示和 Windows 构建产物统一为“数智家校放学系统”。
- Windows Release 产物包含版本化 ZIP 和 SHA256 校验文件。

## 安装或升级

1. 退出旧版客户端。
2. 下载带“数智家校放学系统”中文标签的 Windows x64 ZIP 并解压到独立目录。
3. 运行 `数智家校放学系统.exe`。
4. 首次启动后确认学校绑定、接口连接、MQTT 心跳、服务端放学指令和放学时段数据正常。

## 已知风险和回退

- 正式上线前建议在联调电脑完成一次完整验证：客户端启动、数据同步、MQTT 心跳、服务端指令、刷卡播报和网络日志查看。
- 如需回退，请退出本版本并重新运行独立目录中的 `v1.0.0` 或已验证的 `v2.0.0-beta.2`，不要覆盖原目录。
