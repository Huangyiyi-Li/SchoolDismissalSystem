# v2.0.3 正式版

## 版本类型

正式版修复版本。

## 主要变更

- 修复切换学校后，服务端返回空放学时间时仍显示上一所学校时间的问题。
- 服务端成功返回空时间时会清空本地旧时间，并在主界面显示“未配置”。
- 区分“服务端明确返回空时间”和“接口请求失败”：请求失败时保留上一次有效配置，避免临时网络故障误清空。
- 空时间不再回退到旧版默认时段，避免在未配置放学时间时错误进入刷卡播报状态。
- GitHub Actions Artifact 配额不足时不再阻断正式 Release 下载包发布。

## 安装或升级方式

- 使用 GitHub Actions 基于 `v2.0.3` Tag 构建的 Windows x64 Release 包升级。
- 升级前请退出旧版本客户端，再解压并运行新版 `数智家校放学系统.exe`。

## 已知风险和回退说明

- 未配置放学时间的学校将显示“未配置”，且不会按旧版默认时间处理刷卡。
- 如需回退，请退出本版本并重新运行独立目录中的 `v2.0.1`，不要覆盖原目录。
