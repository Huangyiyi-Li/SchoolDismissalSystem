# v2.1.0-beta.12 LED 年级范围配置版

本版本支持按学校现场需要，只在 LED 屏显示指定年级，同时保持全校所有年级正常语音播报。

## 主要更新

- LED 设置新增“LED 显示年级”，可选择全部年级或指定一个、多个年级。
- 默认继续显示全部年级，升级后不会改变旧版本的展示范围。
- 年级范围仅影响行政班 LED 画面；未选择年级仍正常语音播报、记录日志并推送服务端。
- 社团班展示不受行政班年级筛选影响。
- LED 本地预览、测试画面和正式放学画面统一使用当前年级范围。
- 隐藏年级刷卡后仍保存放学状态，但不会重复发送没有变化的 LED 画面，降低低配置主机负担。
- 预览说明中增加当前 LED 年级范围，方便发布前核对。
- 分页按每一页的实际年级数和最大班级数自适应：年级少的尾页自动增高行高，班级多的年级自动使用更密的列宽，不再保留无效空行。
- 尚未同步班级时，发送测试画面会使用当前选择的年级生成测试内容，不会因年级筛选而发送失败。
- 已保存但本次同步中不存在的年级会标记为“已失效”，避免误判。

## 测试建议

1. 保持“显示全部年级”，确认升级后的画面与旧版本一致。
2. 取消“显示全部年级”，只勾选部分年级，生成预览并确认其他年级不出现。
3. 在测试模式模拟未勾选年级刷卡，确认语音正常播放且 LED 画面不增加该年级。
4. 模拟已勾选年级刷卡，确认语音播放并且 LED 状态正常切换为“放学中/已放学”。
5. 如果学校有社团班，确认行政班年级筛选不会隐藏社团页面。
6. 使用“二、三年级各 14 个班，七年级 28 个班”的数据，确认前一页显示两行，七年级尾页单行自动铺满可用高度。
