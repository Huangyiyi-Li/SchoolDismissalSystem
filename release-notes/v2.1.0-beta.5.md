# v2.1.0-beta.5 LED 多分区与社团班现场测试版

本版本围绕学校现场的 LED 版式配置、社团班放学和测试验收进行优化。

## 本次更新

- 支持行政班与社团班放学状态，两个类型拥有独立状态和放学时段；时段重叠时自动轮播对应页面。
- 测试模式使用独立临时状态：进入测试模式后画面状态置空，退出后恢复当天正式放学状态。
- 模拟刷卡同时支持行政班和社团班，可验证语音、`放学中 → 已放学` 和 LED 画面变化。
- 横向分区数支持 `1–6`，可配置单区、左右双区、三区等布局；同时可设置每区行数。
- 支持关闭左侧标题，关闭后班级内容使用完整屏幕宽度。
- 支持手动填写 LED 像素宽度和高度；预览图片与控制卡动态区域使用相同尺寸。
- 设置页新增本地 LED 内容预览，可查看行政班、社团班及所有翻页，无需连接控制卡。
- 某类放学时段结束时，只清除该类状态，不影响仍处于放学时段的其他类型。
- 本地日志补充关键操作记录，并限制日志文件数量和大小，适配低配置 Windows 主机。

## 现场验证建议

1. 向学校施工方确认 LED 实际像素尺寸，在设置页填写宽度和高度。
2. 分别测试 `1`、`2`、`3` 个横向分区，并通过本地预览确认内容位置和翻页数量。
3. 开启、关闭左侧标题，确认内容区域随设置变化。
4. 在测试模式下分别选择行政班和社团班模拟刷卡，确认语音和 LED 状态正常变化。
5. 退出测试模式，确认当天正式放学状态恢复；重新启动软件，确认正式状态仍然保留。
6. 等待行政班或社团班时段单独结束，确认只清除对应类型的状态。
7. 点击“清空状态/恢复原节目”，确认控制卡恢复施工方预先发送的普通节目。
