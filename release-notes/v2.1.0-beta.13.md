# v2.1.0-beta.13 超高频读卡器与新版设置版

本版本增加超高频读卡器接入和新版系统设置，支持在没有实体设备时使用模拟程序验证完整软件流程。

## 主要更新

- 新增超高频标签协议解析，以及 TCP、UDP 传输和原有近距离刷卡协议兼容。
- 新增读卡设备设置页，支持启用、端口配置、状态提示和采集标签模式。
- 新增学校隔离的 EPC 标签绑定、失效绑定提示和后台卡号映射。
- 超高频标签沿用现有放学时段、语音去重、API 冷却和操作日志流程。
- 新增本机模拟测试窗口、命令行模拟器、抓包工具和 Windows 启动脚本。
- 新增新版系统设置页面及 LED 分组设置、预览入口。

## 验证边界

- 自动化测试覆盖协议校验、TCP 分包与多连接、UDP 收发、原刷卡兼容、绑定持久化、设置保存后重启监听和设置布局。
- 本机模拟窗口已验证首次标签进入播报流程，重复标签会跳过重复播报。
- Windows 真机、实体 LED 和真实 UHF 读卡器仍需设备到场后验收；当前网络格式也需用实际报文进一步比对。
