# v2.1.0-beta.19 放学状态与轮播页面自定义

测试版，构建提交：`{{COMMIT_SHA}}`

## 新增与优化

- 在“屏幕展示 → 样式”中分别编辑“未放学、放学中、已放学”的显示文字；留空即不显示。双色屏可为每种状态分别选择红、黄、绿，单色屏固定红色。放学状态本身及服务端上报不受文案修改影响。
- 在“屏幕展示 → 内容”中按行指定轮播每页的年级，例如第一行“二年级、三年级”，后续行分别填写“四年级”“五年级”“六年级”。每块物理屏可独立配置；留空保持自动分页。
- 标题与表格文字改用相对大小滑杆：100% 为该页能容纳的最大自适应字号，缩小时仍随屏幕尺寸和内容重新适配。预览显示各页计算出的实际字号，年级列宽随表格字号变化。
- 行政班和社团班均应用状态文案与颜色设置；电脑展示和 LED 实体屏共享相同的渲染规则。

## 安装与升级

下载 Windows 安装程序或便携 ZIP。升级前退出旧客户端并备份 `data` 目录。升级后在“系统设置 → 屏幕展示”检查每块屏的年级页面、状态文字与颜色，并生成预览；旧配置留空的每页年级继续自动分页。

如需回退，退出客户端后安装 beta.18 并恢复升级前备份。Windows 自动构建与本地测试不替代现场读卡器、控制卡、双显示器和网络验收。
