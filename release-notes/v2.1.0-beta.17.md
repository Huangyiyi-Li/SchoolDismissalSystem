# v2.1.0-beta.17 多屏放学展示

测试版，构建提交：`{{COMMIT_SHA}}`

## 新增功能

- 支持添加多块 LED 屏，每块屏独立配置 IP、端口、尺寸、颜色和启用状态。
- 支持不同、相同或部分重叠的年级范围。例如南门屏显示一、二年级，北门屏显示三、四年级；也可以两块屏都显示一、二年级。
- 支持共用显示方案；修改年级、标题、字号和布局后，共用该方案的屏幕一起生效，也可复制为独立方案。
- 各屏独立预览、测试、轮播、发送和失败重试；一块屏断线不会阻塞其他屏。
- “恢复此屏原节目”保留全校班级状态；“重置全校今日放学状态”统一清空并恢复所有已配置屏幕。

## 兼容与修复

- 自动读取旧版单屏配置为默认屏幕和默认显示方案，保存后持久化为多屏设置。
- 班级状态及入库只处理一次，保持各屏共享状态一致。
- 停用、移除、交换地址或重新添加同一控制卡时复用物理设备队列，避免旧清屏任务覆盖新画面。
- 恢复原节目失败后显示通信失败，并在客户端运行期间继续重试。
- 切换屏幕清除旧预览，连续保存始终应用最新配置。

## 安装与升级

1. 退出旧客户端，备份原配置和本地数据。
2. 下载 `school-dismissal-v2.1.0-beta.17-setup-x64.exe` 安装；便携使用者可下载 ZIP 解压使用。
3. 打开“系统设置 → LED 屏”，核对默认屏幕，再按需要添加第二块屏并选择显示方案。
4. 分别测试连接与画面，为需要运行的屏幕勾选“启用此屏”并保存。

如需回退，请退出客户端，安装 beta.16 并恢复升级前备份；旧版本只能按单屏配置运行。
