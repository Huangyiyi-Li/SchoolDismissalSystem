# 安卓放学联调：远程诊断与升级契约

目标：测试人员只用 Mac 管理页操作；话机只需保持联网，并在升级时确认一次系统安装。控制卡的真实显示仍以现场观察验收。

## 方案选择

配置、一次性命令和版本发布分开传输。若把命令塞进 30 秒轮询的配置，缓存重放可能重复发送 LED，修改版本又会触发不必要的画面更新。独立控制接口用命令 ID 去重；结果携带命令 ID，管理页能对应一次操作和一次回报。

## 设备接口（Mac 的 8765，经 HTTPS 隧道）

- `GET /api/device-control`：设备令牌鉴权，返回待执行命令及已发布版本。命令只有 `led_ping`、`led_send_page`，每条有唯一 ID 和过期时间。
- `POST /api/device-events`：设备令牌鉴权，上传事件 ID、命令 ID、阶段、成功与否、消息、应用版本、配置版本、控制卡地址。相同事件 ID 重试不重复入库；结果回传成功后才结清命令。
- `GET /api/releases/<sha256>.apk`：设备令牌鉴权，下载已发布的不可变 APK；客户端核对长度、SHA-256、包名、版本和签名后再交给安卓系统安装。
- `GET /pair/<随机令牌>`：仅供现场话机扫码打开配对页；打开应用后更新测试平台地址及令牌。业务设置仍只由服务端下发。

## 管理接口（仅 Mac 本机 8766）

- 查看最近事件、命令状态、设备上报的应用版本。
- 下发一次性“检查连接”或“发送当前班级画面”；旧命令执行完或过期后才能下发新命令。
- 上传签名一致、包名一致、版本号递增的 APK，发布后话机轮询得到更新提示。发布不等于安装；设备用户点击并确认安装才算升级。

## 边界

设备离线时，管理页显示最后上报时间与未完成命令，不能把“已下发”显示成“执行成功”。诊断只保留少量最近事件，不传刷卡号、学生信息或原始串口数据。临时隧道重启后，用新二维码配对，避免每次重建 APK。若话机还未安装支持配对的版本，仍须人工安装一次引导包。
