# 设置工作区

本轮直接调整 PyQt 客户端，保留配置格式和业务行为。不是网页原型。

## 入口与功能位置

| 入口 | 功能 |
| --- | --- |
| 基础设置 | 学校 ID、同步已保存学校的数据（服务可用时）、系统默认／自定义语速、重复次数、每遍间隔 |
| 基础设置 → 连接与高级选项 | 接口地址、设备编号及自动获取、MQTT 心跳／指令开关 |
| 读卡设备 | 近距离刷卡器、超高频 TCP／UDP 接入、端口、标签读取间隔、采集／绑定／解绑、绑定清单及服务状态 |
| 屏幕展示 → 顶部屏幕条 | 切换、添加、移除、启用／停用当前屏；条目显示草稿的启停设置，运行通信状态在悬停提示中查看 |
| 屏幕展示 → 显示范围 | 全部／指定年级、按年级指定班级、搜索当前年级班级、批量选择、已失效班级提示 |
| 屏幕展示 → 布局 | 翻页间隔、每组年级数、行政班横向分区、常规／上下分区／分段轮播、每段列数、自定义每页年级、社团行数／组数、已放学延迟 |
| 屏幕展示 → 样式 | 标题开关、位置与内容，恢复最大自适应文字、两种文字缩放、三种状态的文字与颜色 |
| 屏幕展示 → 样式 → 共享显示方案 | 选择／重命名方案、复制为独立方案、查看影响的屏幕 |
| 屏幕展示 → 设备 | 屏幕名称、LED／电脑切换、控制卡 IP／端口、显示器选择与检测、颜色、像素尺寸、连接测试、测试画面、恢复节目／退出展示、全校状态重置 |
| 屏幕展示 → 固定预览区 | 手动生成预览、前后翻页、实际字号、可读性提醒、缩放、100%／适应窗口、示例状态开关 |
| 底部固定操作栏 | 取消；保存并应用 |

## 交互约定

- 学校与语音设置合并；低频连接参数默认折叠。左侧只保留三个入口。
- 屏幕条、页签、预览和保存操作保持在视野内，参数在当前页签内滚动。编辑区与预览区的分隔线可拖动。
- 显示范围一次编辑一个年级，避免将全校班级垂直堆叠。左侧勾选框控制是否展示年级，箭头切换当前查看的年级。
- 全部年级／全部班级模式允许直接取消某一项，自动转为指定范围。恢复全部班级后，未来同步新增班级也自动展示。
- “全选班级／清空班级”只操作当前年级；搜索时改为“选中搜索结果／清空搜索结果”，只操作匹配项。不影响其他年级和其他屏幕。无搜索结果时禁用批量操作。
- 隐藏年级时保留其班级选择。一个启用展示的年级至少选择一个班级；可以清空后重新选择，但保存及生成预览时会校验。
- 屏幕切换时保留当前草稿，清空上一个屏幕的预览。预览仍需手动生成，不会自动发送到控制卡。
- 保存、运行时应用、学校变更后清理与重新同步、读卡器重启及风险操作的确认逻辑沿用原实现。标签绑定本来就是显式写入数据库的操作，不属于普通表单草稿。
- 最小窗口为 1040×700；班级网格随编辑区宽度换列，参数滚动不遮挡操作栏。Windows DPI 和实体屏需安装后验收。

## 验证

本地测试覆盖入口合并、基础设置保存、搜索及批量选择范围、屏幕独立草稿与重新打开、共享方案、多屏状态及各输出的班级筛选、读卡器保存与采集退出、异步预览、桌面显示器设置和旧配置兼容。

代表性窗口截图使用模拟学校及模拟班级，通过原生 Qt 离屏渲染生成，不能替代 Windows 安装包、设备连接或现场业务验收。
