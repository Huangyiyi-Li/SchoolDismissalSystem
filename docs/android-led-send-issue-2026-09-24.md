# 安卓话机 LED 发送失败问题存档

状态：**搁置开发，待现场恢复排查**。记录时间：2026-09-24。

## 现象

GT-10M 安卓 9 话机运行独立的“放学模块·联调版”。平台已启用 LED，话机点击“检查 LED 连接”后显示已连接；发送班级画面时显示：

> LED 发送失败：发送班级画面失败（控制卡未确认成功）

控制卡为 BX-6E1XP，经局域网连接。测试配置为 `192.168.1.199:5005`、单色屏 `1024×96`。目前没有实体屏成功显示班级画面的验收结果。

## 已确认的事实

- “已连接”来自控制卡 `ping()` 成功；班级画面使用仰邦 Android Ethernet SDK 的 `writeDynamic()`，失败提示来自该调用返回 `!isOK()`。旧版 APK 把 SDK 的具体错误码隐藏了，因此**不能据此认定**是网络、画面格式、控制卡参数或其他原因。
- 2026-09-24 排查时，Mac 无法连接话机此前的 `192.168.1.105:55566` 和控制卡 `192.168.1.199:5005`。这只说明 Mac 当时不能直接做 ADB/控制卡测试；话机已经显示连接成功，不能据此推断话机到控制卡也不通。
- 已构建 v0.4.2 调试 APK：发送失败时展示 SDK 错误，并向 Mac 测试平台回传连接/发送结果。管理页 `http://127.0.0.1:8766/admin` 增加“LED 诊断”和 APK 下载入口；话机通过 8765 的临时 HTTPS 隧道访问。平台接口、本机下载、公开下载和 APK 构建检查通过。
- **v0.4.2 尚未确认安装到话机。**截至归档时，管理页诊断接口返回 `data: null`，尚无话机回传的具体错误。物理 LED 发送与显示未验证。
