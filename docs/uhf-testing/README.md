# 超高频接入与新版设置：测试说明

本版基于 `codex/LED` 开发，分支 `codex/uhf-readers-settings`，版本为 `v2.1.0-beta.14`。尚未进行 Windows 真机或读卡器硬件验收，也未生成 Windows 安装包。

## 没有设备，现在怎么试

Mac 双击项目根目录的「启动超高频模拟测试.command」。本机测试依赖已安装在临时虚拟环境中。

Windows 安装 Python 及 `pip install -r requirements.txt` 后，双击 `tools/start_uhf_demo.bat`。

试用窗口有两个主要入口：

1. **打开新版系统设置**：体验学校绑定、读卡设备、语音播报、LED 屏、高级设置五个页面。LED 内部按连接、内容、样式分组。
2. **模拟读到标签**：使用文档格式生成数据，通过真实的本机 TCP 连接发送；示例标签已绑定一年级1班。首次处理播报，同一时段再次处理跳过重复播报。连续快速发送还会经过 3 秒输入防抖。

所有班级和标签均为模拟数据。模拟程序使用临时数据库、临时配置和自动选择的测试端口；不连接学校 API、MQTT，不发送到实体 LED。关闭后清除试用数据。

语音由本机系统提供；Windows 语音和实体 LED 效果仍须实机检查。设置中的 LED「生成预览」为本地真实渲染。

## 正式程序接入设备

1. 运行 `main.py`，打开「系统设置 → 读卡设备」。启用超高频，默认 TCP 7000，保存后生效。
2. 再次打开设备页，点击「开始采集标签」。采集期间所有 UHF 标签仅录入，不触发放学；近距离刷卡保持原有处理。
3. 用厂家软件配置读卡器：主动模式、18000-6C、单张查询 `Mem_Inven=0x05`；网络客户端目标为放学电脑 IP 和所填端口。产品资料说明 RJ45 需定制，采购时确认型号。
4. 收到标签后选择已同步的班级及原卡号，点击「绑定标签」。这是独立保存动作，取消系统设置不会撤销已保存的标签绑定。
5. 停止采集，再次读卡，按现有放学时段、语音去重和 API 冷却处理。未知或失效绑定仅记日志。

标签绑定按学校隔离，学校同步不会删除。后台卡号被删除、移到其他班级后，绑定显示失效，需要重新绑定。第一版只绑定已有后台卡号，不直接把 EPC 提交为 `cardId`。

## 命令行模拟及抓包

在项目根目录运行，向正在运行的测试监听端口发送（会进入该程序的正常业务，请先开启测试模式）：

```sh
python tools/uhf_simulate.py --port 7000 --split 7 --count 3
python tools/uhf_simulate.py --port 7000 --udp
```

独立原始抓包工具，默认 7001，不能与程序占用同一个监听端口：

```sh
python tools/uhf_capture.py --port 7001
```

## 文档依据与尚需验证的内容

- `3113 一体机如何用网口连接第三方软件TCPUDP服务管理`：读卡器主动作为客户端，服务端监听接收。网络说明将具体格式指向主动模式输出说明。
- `1101 一体机用户手册`：数据格式章节定义 Len 不包含自身；CRC 初值 FFFF、多项式 8408、低字节在前。8.4.9 定义 6C 查询模式的 `Len Adr EE 00 EPC CRC`，EPC 保持原字节顺序。
- `4102 中距离一体化读写器1861-8dbi`：网口属于定制接口。

当前网络解析根据这两份文档组合实现，还没有实际网络报文证明网口模块完全透传该格式。设备到场后用抓包工具比对。`EE 00` 同时用于部分其他存储区输出，单凭报文无法证明其内容是 EPC，因此设备必须配置为 6C 查询模式；暂不支持 6B、TID、用户区或应答轮询。

## 验收清单

- [ ] 模拟标签首次触发一年级1班，重复读不重复播报。
- [ ] 采集标签期间不触发 UHF 放学，退出设置后恢复正常处理。
- [ ] 绑定新标签，重开设备页仍存在；同步不删除绑定。
- [ ] 学校切换后不能使用上一学校的标签绑定。
- [ ] 保存端口后立即生效；端口被占用时显示失败提示。
- [ ] 五个设置页面可切换，保存和取消始终可见。
- [ ] LED 的连接、内容、样式及预览可用。
- [ ] Windows 实机：语音、原近距离刷卡器、实体 LED 均正常。
- [ ] 真读卡器：首次报文匹配、长时间读取、离开再进入、断线重连。

## 本轮验证结果

209 项自动化测试通过，包括协议校验、TCP 分包/多连接、UDP 收发、原刷卡协议兼容、绑定持久化、保存后重启监听和设置布局。使用真实 Qt 测试环境运行，无跳过项。

本机模拟窗口已实际点击验证：首次标签进入语音播报流程，第二次同班标签显示重复播报并跳过。这里验证的是模拟输入和软件流程，不代表设备或 Windows 硬件验收。
