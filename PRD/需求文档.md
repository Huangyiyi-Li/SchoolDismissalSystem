# 校园放学语音播报系统 - 需求规格说明书 (PRD)

## 1. 引言

本系统旨在通过 IC 卡刷卡触发，实现自动化、数字化的放学语音提醒。系统通过 **UDP** 协议监听指定端口接收刷卡器数据，根据预设逻辑进行去重、校验后，使用 TTS 技术进行语音播报。

## 2. 技术架构

- **开发语言**: Python 3.10+
- **GUI 框架**: PyQt6
- **网络通信**: **UDP Socket (Datagram)**
- **数据库**: SQLite 3
- **语音合成**: pyttsx3 (离线 TTS)

## 3. 功能需求

### 3.1 硬件通信 (UDP 服务端)

- **协议**: **UDP**
- **端口**: **39169** (固定)
- **协议解析**:
  - **包长**: 固定 22 字节
  - **格式定义**:

    | 字节偏移 | 长度 | 说明 | 示例 (HEX) |
    | :--- | :--- | :--- | :--- |
    | 0 | 1 | 头部 (固定?) | `C1` |
    | 1-4 | 4 | 源 IP 地址 | `C0 A8 01 DA` (192.168.1.218) |
    | 5-8 | 4 | 流水号/序号 | `00 00 01 00` |
    | 9-10 | 2 | 未知/保留 | `00 C1` |
    | 11-14 | 4 | 设备标识? | `16 F4 D9 7D` |
    | 15-18 | 4 | **IC 卡号 (UID)** | `63 D0 7B 54` |
    | 19-21 | 3 | 尾部/校验 | `50 98 16` |

  - **关键提取**: 提取第 15-18 字节转换为 HEX 字符串作为 `card_id`。

- **设备管理**:
  - 以 `源 IP` 或 `设备标识(Bytes 11-14)` 作为设备唯一 ID。
  - **在线状态**: 记录最后接收数据的时间，超时 60s 判离线。

### 3.2 业务逻辑

- **卡号识别**:
  - 接收 UDP 包 -> 解析卡号。
  - 查询数据库 `mapping` 表 -> 获取“班级名称”。
- **有效性校验**:
  - **时间窗口**: 仅在设定时间段（配置文件可配，如 16:30-18:30）内有效。
  - **非播报时段**: 记录日志，但不触发播报。
- **防抖与去重**:
  - **全局去重**: 同一班级在同一有效时间段内仅播报一次。
  - **重置机制**: 下一个时间段开始时，重置所有班级的播报状态。

### 3.3 语音播报

- **播报内容**: `[班级名称]正在放学`，重复 3 遍。
- **队列管理**:
  - 采用 FIFO（先进先出）队列处理并发刷卡。
  - 播报过程独立于网络线程，确保不阻塞 UDP 接收。
- **TTS 引擎**: 使用 `pyttsx3` 实现本地离线语音合成。

### 3.4 用户界面 (UI)

主要包含四个功能区域：

1. **连接状态区**: 显示最近活跃的设备列表（IP | 最后活动时间 | 状态）。
2. **实时日志区**: 滚动显示系统事件（刷卡、播报、错误等），包含时间戳。
3. **配置/状态区**: 显示当前生效的时间段配置。
4. **待播报队列**: 显示当前正在排队等待播报的班级。

### 3.5 数据存储

使用 SQLite 数据库 `school.db`。

**表1: mapping (卡号映射)**

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER | 主键 |
| card_id | TEXT | IC卡内码 (Unique) |
| class_name | TEXT | 班级名称 |

**表2: logs (通过记录)**

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER | 主键 |
| swipe_time | DATETIME | 刷卡时间 |
| card_id | TEXT | IC卡内码 |
| status | TEXT | 状态 (播报成功/时间外/重复/未匹配) |
